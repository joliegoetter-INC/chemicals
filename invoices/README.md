# Invoices (Carl drops files here)

Drop vendor invoices, packing slips, or order confirmations here. PDFs, photos, or forwarded emails saved as PDF are all fine. Any file name works.

What gets pulled from them:
- Received date (invoice or ship date, used as an approximate received date).
- Vendor catalog number and lot number, to match the invoice line to a bottle.
- CAS number or full product name, for bottles whose label has no CAS.

Nothing here is edited or deleted. Matches are written to the inventory with source = "invoice".
